# pedal-controller-prototype

Musicians, especially live, use pedals to change how they sound. Pedals can be quickly turned on and off and can have parameters that can be easily changed by the user.

This project is a control board for such a pedal. The main function of the board is to send values of digital potentiometers to an audio signal processor. The audio part is outside the scope of this project.

The board includes the ability to adjust the values of the digital potentiometers with physical potentiometers and the ability to save and load values to send to the digital potentiometers. The output signal can be toggled with a button, and the board can cycle between 2 presets and a direct physical to digital potentiometer mode by long pressing the same button. The user can edit presets by tuning the potentiometers and the edited preset can be saved by pressing a second button. Two LEDs show the state of the system.
